# 🚀 模块化编程脚本助手 - 使用指南

## 📦 文件夹内容

本文件夹包含 STM32 CMake 自动配置脚本系统的所有文件：

| 文件名                    | 说明                                          |
| ------------------------- | --------------------------------------------- |
| **fix_cmake_user.ps1**    | PowerShell 核心脚本（自动扫描并配置所有模块） |
| **fix_cmake_user.bat**    | 批处理启动器（可双击运行）                    |
| **run.bat**               | 简化版启动器（推荐使用）                      |
| **QUICK_START.md**        | 快速开始指南（必读）                          |
| **README_CMAKE_SETUP.md** | 详细使用文档（遇到问题时参考）                |

---

## ✨ 功能说明

这套脚本可以：

✅ **自动扫描** `User/Src` 目录中的所有 `.c` 文件  
✅ **智能添加** 到 CMakeLists.txt（无重复）  
✅ **支持无限个模块** 无需手动修改配置  
✅ **完全幂等** 运行多次不产生副作用  
✅ **中文完全支持** 路径和文件名均可中文

---

## 🎯 快速使用

### 场景 1：STM32CubeMX 重新生成代码后

1. **打开 VS Code 集成终端**（Ctrl + `）
2. **运行命令**：
   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File fix_cmake_user.ps1
   ```
3. **重新编译项目**

---

### 场景 2：添加新模块

1. **在 `User/Src` 中创建** `your_module.c`
2. **在 `User/Inc` 中创建** `your_module.h`
3. **运行脚本**（见上方命令）
4. **自动添加到编译列表**

---

### 场景 3：快速运行

直接**双击** `run.bat` 文件

---

## 🔧 如何部署到其他项目

要在另一个 STM32 项目中使用这套脚本：

1. **复制整个文件夹** 到项目根目录
2. **重命名文件夹名称**（可选）
3. **按上述方式运行脚本**

脚本会自动识别当前目录结构并进行配置。
